# Telzino Examples

Public example scripts for [Telzino](https://telzino.com) voice agents. Each folder pairs with a guide on the Telzino docs site.

| Folder | What it is | Guide |
| :- | :- | :- |
| [`appointment-confirmation`](appointment-confirmation) | Google Apps Script that calls customers from a Google Sheet to confirm appointments and writes each call's result back to the row | [Appointment Confirmation](https://docs.telzino.com/examples/appointment-confirmation) |
| [`google-sheet-crm`](google-sheet-crm) | Google Apps Script that lets a receptionist agent look up callers, reschedule appointments, open tickets and log calls in a Google Sheet | [Receptionist Agent Using Google Sheets as Simple CRM](https://docs.telzino.com/examples/google-sheets-crm-receptionist) |
| [`claude-skill`](claude-skill) | A Claude skill that reads your agents' call logs over the Telzino API to explain failed calls, and makes agent changes with a backup first. Download [`telzino-skill.zip`](claude-skill/telzino-skill.zip) and upload it to Claude | [Troubleshoot Agent Calls with an AI Assistant](https://docs.telzino.com/configure-with-ai/troubleshoot-calls-with-ai) |

## Using a script

Open the file on GitHub, click **Copy raw file**, and paste it where the guide tells you to. Copy from GitHub rather than from an email or Word document, which can turn straight quotes into curly quotes and break the code.

The example business and customer data in these scripts are fictional.
